Project Title: Helpful tips for beginners in python


Description: This project aims to provide helpful tips in coding to users who have just begun learning python.

Reflection: Do you experience conflicts? 

Yes, my partner and I experienced a few merge conflicts while working together on the repository, especially when we were both editing the Readme file at the same time.

What steps helped avoid merge conflicts?

We avoided further merge conflicts by dividing the file into separate sections so we didn’t edit the same line at the same time.
How did code review improve the final result?

By reviewing each other’s work, we caught some typos and format mistakes while keeping the layout consistent across the whole Read me file.

What was challenging about collaborating with Git and GitHub?

The most challenging thing was remembering to pull and push requests while trying to not overwrite each other’s commit.
